📚 VOCABULARY

Box Plot: A graphical representation of data that shows the distribution based on a five-number summary. It includes a box that represents the interquartile range and lines (whiskers) that extend to the minimum and maximum values.

Five Number Summary: A set of descriptive statistics that provide information about a dataset. It includes the minimum, first quartile (Q1), median (Q2), third quartile (Q3), and maximum.

Frequency: The number of times a data point appears in a dataset. In a histogram, it's represented by the height of the bars.

Histogram: A type of graph that shows the frequency of data within equal intervals or bins. It's used to visualize the distribution of numerical data.

Interquartile Range (IQR): The difference between the third quartile (Q3) and the first quartile (Q1) in a dataset. It measures the spread of the middle 50% of the data.

Intervals (Bins): The equal divisions or ranges of values in a histogram. Each bin groups a range of data, showing how many data points fall within that range.

Minimum: The smallest value in a dataset.

Maximum: The largest value in a dataset.

Numerical Data: Data that consists of numbers. It can be discrete (countable) or continuous (measurable).

Outlier: A data point that is significantly different from the other data points in a dataset. Outliers can be much higher or lower than the rest of the data.

Quartiles: Values that divide a dataset into four equal parts. The first quartile (Q1) is the median of the lower half of the data, the second quartile (Q2) is the median of the dataset, and the third quartile (Q3) is the median of the upper half of the data.

💡 EXPLORING THE MATH

In today's lesson, we will be exploring how to use a set of numerical data to create a five-number summary and use that summary to draw a box plot representation of the data set. We will discuss what the box plot shows us and can tell us about the data set. Box plots are like treasure maps; they show us the distribution of a data set at a glance, highlighting its central values and spread. To create one, we use something called the five-number summary. Let's dive in and discover how to make and interpret box plots!


Let's begin by looking at what makes a box plot.

What is a Box Plot?

A box plot is a graphical representation of a data set that shows the distribution of the data across five main points: the minimum, the first quartile (Q1), the median, the third quartile (Q3), and the maximum. These five points make up the five-number summary. Here’s what each part tells us:

  • Minimum: The smallest number in the data set.
  • Q1 (First Quartile): The median of the lower half of the data set. This is the 25th percentile.
  • Median: The middle value of the data set. This is the 50th percentile.
  • Q3 (Third Quartile): The median of the upper half of the data set. This is the 75th percentile.
  • Maximum: The largest number in the data set.

The space between Q1 and Q3 is called the interquartile range (IQR), and it represents the middle 50% of the data. The longer this box, the more spread out the middle 50% is.


How to Create a Box Plot

  1. Draw a Number Line: This should be long enough to include your maximum and minimum values.
  2. Plot the Five-Number Summary: Mark the minimum, Q1, median, Q3, and maximum on the number line.
  3. Create the Box: Draw a box from Q1 to Q3 with a line in the middle for the median.
  4. Add the Whiskers: Draw lines ("whiskers") from the ends of the box to the minimum and maximum values.
