📚 VOCABULARY

Area: The amount of space inside a flat shape, measured in square units.

Cube: A three-dimensional shape with six equal square faces.

Dimension: A measurement of length, width, or height of a shape or object.

Model: A representation or example of a shape or object used to help understand math concepts.

Net: A flat, two-dimensional pattern that can be folded to form a three-dimensional shape.

Rectangular Prism: A three-dimensional shape with six faces, where all faces are rectangles.

Rectangular Pyramid: A three-dimensional shape with a rectangular base and triangular faces that meet at a single point.

Slant Height: The height of the slanted side of a pyramid, measured from the base to the top along the surface.

Surface Area: The total area of all the faces or surfaces of a three-dimensional shape.

Volume: The amount of space inside a three-dimensional shape, measured in cubic units.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how to find the volume of a prism by using a model packed with cubes, like the one shown in the image. A prism is a three-dimensional shape, and volume is the amount of space it takes up. When we calculate the volume of a prism, we are finding how many cubic units (small cubes) fit inside the prism. By the end of this lesson, you will know how to count the cubes in one row, use repeated addition to find the area of the base, and then stack the bases using repeated addition to find the total volume of the prism.


Understanding the Model

Let’s look at the model in the image. The prism is packed with cubes, and we want to find out how many cubes are inside. To do that, we need to start by finding how many cubes fit in one row, then find how many rows there are to calculate the area of the base, and finally stack the base to figure out the height.

Step 1: Finding the Cubes in One Row

First, we focus on one row of cubes on the bottom layer. This row runs along the length of the prism. By counting the cubes in this row, we can see how many cubes make up one row.

  • Let’s say that the length of the prism, from left to right, is 4 cubes long. So, one row contains 4 cubes.

Step 2: Finding the Number of Rows (Using Repeated Addition)

Next, we need to figure out how many rows are in the base of the prism. Each row runs from left to right, and the number of rows is determined by the width of the prism. If the width of the prism is 3 cubes, then there are 3 rows of cubes.

To find out how many cubes are in the entire base of the prism (the bottom layer), we can use repeated addition. Since each row has 4 cubes and there are 3 rows, we add them up .

So, the area of the base is 12 cubes. This is called the area of the base because it represents the number of cubes that fit on the bottom layer.

Step3: Stacking the Bases to Find the Height (Using Repeated Addition)

Now that we know how many cubes are in the base, we need to stack the base for each layer of the prism to calculate the total volume. The number of layers is determined by the height of the prism. If the height of the prism is 4 cubes, we will stack the base 4 times.

Again, we can use repeated addition. Since the base has 12 cubes, we add them up 4 times, one for each layer .

So, the total volume of the prism is 48 cubic units.


Putting It All Together

To summarize:

  • The length of the prism is 4 cubes, so each row has 4 cubes.
  • The width of the prism is 3 cubes, so the base has 3 rows of 4 cubes.
  • The area of the base is 4+4+4=12 cubes.
  • The height of the prism is 4 cubes, so the total volume is 12+12+12+12=48 cubic units.


Conclusion

By using this model packed with cubes, we can easily calculate the volume of a prism. First, we find the number of cubes in one row, then use repeated addition to find the area of the base by adding the number of rows. Finally, we stack the base as many times as the height of the prism to find the total volume using repeated addition. This method helps us understand that the volume of a prism is simply the number of cubes it can hold!
