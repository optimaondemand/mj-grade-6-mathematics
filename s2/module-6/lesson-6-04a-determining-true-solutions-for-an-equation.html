📚 VOCABULARY

Inequality: A mathematical statement that shows the relationship between two values, where one value is not necessarily equal to the other. It tells us if one value is less than, greater than, less than or equal to, or greater than or equal to the other value.

Equation: A mathematical statement that shows that two expressions are equal. It uses an equal sign = to show that the values on either side are the same.

Inequality Symbol: A sign used to show the relationship between two values in an inequality.

Number Line: A straight, horizontal line with numbers placed at equal intervals along its length. It is used to visually represent numbers and their relationships, such as showing where a number lies compared to others or representing inequalities and solutions.

Solution: A value that makes an equation or inequality true. For example, if you have the equation x+2=5, the solution is x=3 because 3 + 2 equals 5.

Solution Set: A set of all values that make an equation or inequality true. For inequalities, the solution set includes all possible values that satisfy the inequality. For example, for the inequality x>2, the solution set includes all numbers greater than 2.

Substitution: A method used to check if a value is a solution to an equation or inequality. It involves replacing the variable with the given value and performing the calculations to see if the equation or inequality is true.

Variable: A symbol, usually a letter, that represents an unknown value in an equation or inequality. In one-variable equations and inequalities, there is only one variable to solve for.

What is a True Solution to an Equation?

How to Use the Substitution Method

The substitution method involves replacing the variable in the equation with a given value to check if it makes the equation true. Here’s how you do it:

  1. Identify the variable in the equation.
  2. Substitute the given value for the variable.
  3. Perform the arithmetic operations.
  4. Check if both sides of the equation are equal.
