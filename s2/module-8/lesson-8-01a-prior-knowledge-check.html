📖 PRIOR KNOWLEDGE

In a previous grade, you learned about the first quadrant of the coordinate plane and how to plot points in the first quadrant. As we get ready to learn about the whole coordinate plane, plotting rational numbers, and using all four quadrants, it is important to review the first quadrant and plotting whole numbers. The coordinate plane can be divided into whatever size increments we need in order to graph points. Let's begin with dividing the coordinate plane into whole number increments.


The Coordinate Plane

  • The first quadrant of the coordinate plane contains the positive x values and the positive y values.
  • The x-axis runs to the right, horizontally, and the y-axis runs up, or vertically.
  • The origin is in the left bottom corner and represents the point (0, 0)

In the image, point A represents the origin.

Point B is on the x-axis and point C is on the y-axis.

Point D is in the quadrant. It represents the point with coordinates (4, 5). This tells us the point is 4 units to the right and 5 units up.

A coordinate point is written in the form (x, y) where the first number tells you the number of units to move on the x-axis, right, and the second number tells you the number of units to move on the y-axis, up.


Example 1

Plot the point (3, 5) on the coordinate plane.

  • To plot the point, we will start at the origin and move 3 units to the right, then 5 units up.


Example 2

Plot the point (3, 0).

  • To plot this point, we will move 3 units right and stay. The value of y is 0, which tells us to move up 0 units. This point will be on the x-axis since the value of y is 0.


Example 3

Plot the point (0, 4).

  • To plot this point, the value of x is 0. So, we move 0 units to the right. Then we move up 4 units. This point will be on the y-axis since the value of x is 0.


Conclusion

Plotting points is like navigating a map. The value of x tells us how many units to move to the right and the value of y tells us how many units to move up. If we are given a coordinate point, we can use the values to navigate to that location. If we are given a point already plotted, we can start at the origin and navigate to that point, identifying how many units to move right and up as we go. In the next lesson, we will be exploring the whole coordinate plane with positive and negative values.
