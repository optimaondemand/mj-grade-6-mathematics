# mj-grade-6-mathematics

Lesson and assignment pages for M/J Grade 6 Mathematics (1205010), Semester 2, served on GitHub Pages and embedded
by `<iframe>` in the Course Kit cartridge (`optimaondemand/optima-courses-2026-27`). Generated from the reformatted
course; do not edit pages by hand.

## s2-sparkle

Sparkle (integrated) version of Semester 2, lessons 6.01a to 9.02d: one page per lesson, embedded by the kit `1205010-s2-sparkle` as a PDF-upload assignment. The original pages in `s2/` are unchanged and still serve the kit `1205010-s2`. `s2-sparkle/take-into-vr/` holds the picture cards the Course Optimizer offers to live teachers (rendered by `_shared/vr-pack/render_vr_pack.py`). Sources and build tools are kept in the curriculum workshop folder, not here.
